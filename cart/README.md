# Cart component

## assignment01
Potrebno je da kreirate React komponentu Cart koja prikazuje sadržaj korpe za kupovinu. Komponenta treba da bude napravljena po uzoru na prikazani dizajn: svaki proizvod u korpi ima sliku, naziv, odabranu boju, odabranu veličinu, cenu, kontrolu za količinu i opciju za uklanjanje proizvoda.

Na dnu korpe treba prikazati ukupan iznos svih proizvoda.
